Mesodisk wipes and formats each disk you plug in, then shows its full S.M.A.R.T. report from CrystalDiskInfo. It's built for working through a stack of drives.

One cycle per drive

Set it up once, then keep swapping drives. The results stay on screen until the next new disk goes in.

  1. Arm

    Choose FAT32, exFAT or NTFS and a volume label, then press ARM. If no new disk arrives for 15 minutes, Mesodisk disarms itself.

  2. Insert a drive

    Mesodisk erases it, creates one partition and quick-formats it. Extra drives inserted together are queued and handled one at a time.

  3. Read the result

    The health verdict, every S.M.A.R.T. attribute, and the new file system, label, drive letter and free space appear on one screen.

It won't touch the wrong disk

Formatting erases data, so Mesodisk refuses to format a disk if:

  • it was connected when Mesodisk started, even if you unplug it and plug it back in
  • Windows reports it as the boot or system disk
  • it is a virtual disk, or a card reader with no card in it
  • Mesodisk is disarmed. The drive still gets its health check, and a confirmed "Format this disk now" is available.

What you see

Everything about the drive you just processed, on one screen.

Health verdict
CrystalDiskInfo's Good, Caution or Bad, with the health percentage, temperature, power-on hours and data written.
Format summary
File system, label, drive letter, capacity and available space, or the reason the drive wasn't formatted.
All S.M.A.R.T. attributes
Current, worst, threshold and raw values. Failing attributes are shown in red and warning signs in amber.
Full report
CrystalDiskInfo's own text report for the drive, plus the diskpart output.

The exe isn't code-signed yet, so Windows SmartScreen may say the publisher is unknown. Choose More info, then Run anyway. Mesodisk asks for Administrator rights because Windows only lets elevated programs format disks and read S.M.A.R.T. data. Previous versions
